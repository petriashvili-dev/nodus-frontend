# Nodus — дизайн-система

Как Nodus выглядит, звучит и говорит. Любой новый экран, компонент или текст должен выглядеть так, будто он был в приложении всегда. Интеграция с backend (sync, AI, шаринг) добавляет **новые состояния**, но не новый визуальный язык. При конфликте с общими советами скиллов прав этот файл.

## 1. Философия

**Нить и узлы.** Время — это нить, дела — узлы на ней. Пользователь *завязывает* узел (намерение), *развязывает* (сделал) и *перевязывает* (вернул в работу). Метафора — это и есть интерфейс: она проходит через формы, анимации и тексты.

Принципы:

1. **Тишина вместо шума.** Тёмная ночная сцена, тёплый свет, медленное движение. Ничего не мигает, не кричит, не требует внимания без причины. Без геймификации: ни очков, ни серий, ни конфетти.
2. **Мгновенность.** Любое действие отражается сразу. Сеть, sync и AI работают за кадром; спиннер на месте контента — признак ошибки дизайна.
3. **Минимум полей.** Создание — название и время; остальное раскрывается по необходимости.
4. **AI предлагает, человек решает.** Предложения AI выглядят как мягкая подсказка, которую легко принять, поправить или проигнорировать.
5. **Деликатность.** Ошибки и конфликты сообщаются спокойно и честно, без красных тревог и без потери данных пользователя.
6. **Свет — это смысл.** Акцентное золото означает «живое и важное»: активный узел, главное действие, нажатие. Не тратить его на декор.

## 2. Цвет

Сцена **только тёмная** (navy-ночь) — это зафиксированное решение. Светлую тему и светлые варианты экранов не делать, даже если она упоминается в продуктовых документах.

Токены — `Components/NodusPalette.swift`. В экранах использовать токены, не литералы `Color(hex:)`; новый цвет сначала добавить в палитру (или в приватный `enum` компонента, как в `OnboardingView`) и в эту таблицу.

| Токен | Hex | Роль |
|---|---|---|
| `background` | `#0B1020` | фон сцены и листов |
| `surface` | `#151C2E` | приподнятые плашки (toast) |
| `accent` | `#C9A46A` | фирменное золото: нить, главный CTA, выделение |
| `primary` | `#FFFFFF` | основной текст (обычно с opacity 0.9–0.96) |
| `secondary` | `#94A3B8` | вторичный текст, даты, подписи |
| `dim` | `#64748B` | третичный текст |
| `softLine` | `#273449` | тонкие разделители |

Тёплые оттенки золота (в компонентах, не в палитре):

| Hex | Где |
|---|---|
| `#F5D7A8` | текст и иконки на золотых кнопках |
| `#F0C98B` → `accent` | градиент обводки кнопок |
| `#F7D9A5`, `#FFEACB` | свечение и обводка при нажатии (`NodeButtonStyle`) |

Семантика состояний узла (`TimelineService.tint`):

| Состояние | Hex | Смысл |
|---|---|---|
| одноразовый | `#94A3B8` | нейтральный |
| регулярный | `#8EA37D` | приглушённый зелёный |
| ежегодное событие / «сейчас» | `#C9A46A` | золото |
| развязан | `#8FAE93` | бледно-зелёный: «сделано» читается как отдельное состояние |
| потерян (просрочен) | `#A78368` | выцветшее золото, без тревожного красного |
| деструктивное действие | `#D8A48F` на `#2A1414` | тёплый терракотовый, не системный red |

Правила:

- Прозрачность — основной инструмент иерархии: один цвет, разная opacity. Завершённое и потерянное приглушается (≈0.4–0.6), а не перекрашивается.
- Системные `.red`, `.blue`, `.green`, `.accentColor` в UI не использовать.
- Новые состояния sync (pending/failed/conflict) строятся из этой же палитры: pending — без цвета вообще, failed/conflict — оттенок «потерянного» (`#A78368`) или деструктивного терракотового.

## 3. Типографика

| Роль | Шрифт | Примеры |
|---|---|---|
| Голос бренда: приветствие, дата, заголовки узлов, тексты кнопок, подписи состояний | **Cormorant Garamond** (`Font.cormorant`) | приветствие 26 Regular; дата 18 Light; заголовок карточки 18 Regular; описание 14 Light; CTA 16–17 Regular; подпись «развязанный узел» 11 Regular + `tracking(0.6)`; онбординг 21–28 Light Italic |
| Интерфейс: заголовки листов, поля, чипы, toast, настройки | **SF Pro** (`.system`) | заголовок листа 17 Semibold; тело 13–15 Regular/Medium; мелкие подписи 11–12 Medium/Semibold; toast 15 Medium `.rounded` |

- Набор шрифтов зафиксирован: Cormorant Garamond + системный SF Pro. Новые шрифты (в т. ч. Manrope из продуктового описания) не добавлять.
- Доступные начертания Cormorant: Light, Regular, Light Italic (`Resources/Fonts`, регистрирует `FontRegistrar`). Bold Cormorant не использовать — акцент делается размером, курсивом или светом.
- Новые тексты должны масштабироваться с Dynamic Type там, где это не ломает композицию (`relativeTo:` / `@ScaledMetric`).

## 4. Форма и поверхности

- Скругления только `style: .continuous`: карточка и секция листа — **18**, поля и чипы — **14**, toast — **20**, кнопки — `Capsule`.
- **Карточка узла** (`EventCard`): «матовое стекло» — `.ultraThinMaterial` + тёмный градиент (`#20232A` → `#171A20`, opacity 0.62), обводка `primary` 0.07, мягкая тень `black` 0.18, radius 20, y 12. Тип узла показывает цветная точка-маркер, а не текстовая метка.
- **Главная кнопка** (`NewNodeButton`): прозрачная capsule на `background` 0.58 + золото 0.05, светящаяся золотая обводка. Вторичная круглая — `IconCircleButton`.
- **Кнопки листов** (`NodusSheetFooterButton`): тоны `primary` / `secondary` / `destructive`.
- **Разделители**: не прямая линия на всю ширину, а затухающий градиент (`NodusOrnamentDivider`, `NodusWaveDivider`, разделитель под фразой на главной).
- **Листы**: `NodusPlainSheetScaffold` — тот же `Backdrop`, отступы 22, интервал секций 18, только `.large`, свой индикатор перетаскивания.
- Тени тёмные и мягкие, плюс лёгкое золотое свечение у интерактивного. Жёстких рамок и плоских непрозрачных плашек нет.

## 5. Сцена и движение

- **`Backdrop`** — живой фон: пятна тёплого света медленно дрейфуют (периоды 20–60 мин, ниже порога восприятия), их положение и сила следуют времени суток; ночью экран темнеет и появляются редкие звёзды. Палитра не меняется — меняется только свет. Каждый полноэкранный экран и лист стоит на `Backdrop` (заставки — на `StaticBackdrop`).
- **Нить** (`TimelineThread`) — плавная кривая с петлями-узлами; это главный графический элемент. Не заменять её списком с буллетами или стандартной timeline-линией.
- Темп движения — медленный и мягкий:

| Что | Анимация |
|---|---|
| появление экрана / элементов | `easeOut(0.8)` с задержкой 0.18; каскад строк ленты — `spring(response: 1.15, damping: 0.9)` + `0.08 × index` |
| нажатие | `NodeButtonStyle`: масштаб 0.92/0.96 + золотое свечение, `spring(0.28, 0.6)` |
| выбор чипов, переключатели | `spring(response: 0.32, damping: 0.78)` |
| смена текста / значения | `easeInOut(0.24–0.35)` |
| «дыхание» пустого состояния | `easeInOut(6)` бесконечно, масштаб 0.98↔1.02 |

- `accessibilityReduceMotion` уважается везде: дыхание, дрейф и каскады отключаются или заменяются простым fade.
- Появление совместного узла от другого человека — мягкая анимация на нити, не модальное окно.

## 6. Звук и тактильность

- Звуки — `nodus/nodus/Sounds/`: `splash.wav` (ритуал заставки, `SplashRitualView`) и `notify.wav` (звук локальных уведомлений). Новые звуки — такие же тихие и короткие, в ту же папку.
- Лёгкий тактильный отклик (`UIImpactFeedbackGenerator(.light)`) сопровождает ключевые жесты на узлах и ритуал заставки.
- Каналы управляются настройками (`hapticsEnabled`, `inAppSoundsEnabled`, `notificationSoundEnabled`) и **всегда** проверяются перед воспроизведением.
- Ошибки и фоновая синхронизация звуком и вибрацией не сопровождаются.

## 7. Язык и тексты

Две локали: `ru` (основная) и `en`; ключи — английские фразы в `Localizable.strings`.

Словарь:

| Понятие | ru | en |
|---|---|---|
| задача/событие | узел | knot |
| создать | завязать | tie |
| выполнить | развязать | untie |
| вернуть в работу | перевязать | retie |
| просроченный | потерянный узел | lost knot |
| лента | нить (времени) | thread (of time) |
| голосовой AI-разбор | «Распутываем мысли…» | — |
| AI-предложение следующего шага | продолжение нити | thread continuation |
| настройка согласия на AI | AI-помощник | AI assistant |

Тон:

- Спокойный, тёплый, короткий; на «ты» (`Один узел еще ждет тебя`).
- Подтверждения — короткие фразы без восклицаний (`Узел завязан`); точка в toast отбрасывается.
- Пустые состояния — образ, а не инструкция: «Сегодня нить свободна», «Все узлы развязаны».
- Не использовать слова «задача», «таск», «удалить навсегда», «ошибка сервера», коды ошибок и технический жаргон («синхронизация не удалась: 409»). Пользователь видит смысл: «Узел изменили на другом устройстве».
- Числительные склоняются (`yearWord` в `EventCard`) — не писать «1 лет».
- Недоступная функция не упоминается: никаких замков, бейджей, «скоро», Nodus+, подписки или тестирования. Если сервер всё же отказал — нейтрально: «Эта функция сейчас недоступна».

## 8. Паттерны обратной связи

- **Toast** (`ToastView`) — вверху нити, похож на системный баннер, не перекрывает задачу; для обратимых действий — «Отменить» с полосой прогресса.
- **Деструктивное** — через toast с отменой, а не через alert, где это возможно.
- **Pending sync** — без спиннеров на карточках; максимум ненавязчивый общий индикатор.
- **Failed / conflict** — тихий статус на карточке (подпись Cormorant 11 + tint) и общий список «Не удалось синхронизировать» с действиями «Повторить» / «Отменить». Конфликт совместного узла — выбор «оставить моё / оставить их», никогда не молчаливая перезапись.
- **AI-черновики** — `AIDraftsReviewView`: карточки (поверхность секции, Cormorant 19 для названия, системный 13 для даты), кружок-галочка включает/исключает, тап открывает обычный редактор узла; проблема — тёплый tint `#D8A48F` в подписи и обводке. Одна кнопка `NodusSheetFooterButton` подтверждает все; до подтверждения на нити ничего нет.
- **Ожидание AI** — `AIDraftsWaitingCard` на месте composer: палочка с пульсом (без анимации при Reduce Motion), «Распутываем мысли…» Cormorant 28; подпись про закрытие экрана — только после того, как сервер принял задание.
- **Голосовая запись** — `VoiceInputComposer`: компактная тёмная карточка с тихой верхней подписью и отдельной кнопкой закрытия; заголовок Cormorant, центральный круг записи с золотой кнопкой микрофона/остановки, волной и тонкой нитью прогресса, затем поле «Твои слова» и одна главная capsule-кнопка «Завязать». Волна статична при Reduce Motion; поле получает фокус только по нажатию, чтобы клавиатура не открывалась сама.
- **Импорт AI** — `ImportJobReviewView`: preview в настройках, строки можно исключать переключателем; нижняя золотая кнопка подтверждает только выбранные записи, отмена остаётся вторичным действием.
- **Продолжение нити** — однократное мягкое предложение после развязывания, показывается мгновенно из кеша; если его нет — ничего не ждём и не показываем.
- **Согласие на AI** — отдельный экран (не alert) при первой попытке открыть AI-функцию: какие данные и кому отправляются, зачем, ссылка на privacy policy; «Разрешить» / «Не сейчас». Если из AI есть только продолжение нити — один ненавязчивый показ, отказ больше не переспрашиваем. В настройках — переключатель «AI-помощник», виден только при доступных AI-функциях.
- **Системные alert** — только для разрешений и необратимых решений (удаление аккаунта).
- **Обязательное обновление** — `UpdateRequiredView`: полный экран поверх всего, логотип, заголовок Cormorant Italic, одна кнопка «Обновить» (если есть ссылка App Store). Предложение необязательного обновления — обычный toast, не чаще раза в сутки.

## 9. Чек-лист нового UI

- [ ] Шрифты: Cormorant для голоса бренда, системный для интерфейса; без Bold Cormorant.
- [ ] Золото — только у живого и главного; состояния показаны прозрачностью и tint.
- [ ] Скругления continuous 14/18/20, кнопки capsule, мягкие тени.
- [ ] Анимации медленные, Reduce Motion учтён.
- [ ] Звук/вибрация — через настройки.
- [ ] Тексты в обеих локалях, словарь узлов соблюдён, нет технического жаргона.
- [ ] Действие мгновенное, сеть не блокирует, ошибки сообщаются спокойно.
- [ ] VoiceOver: осмысленные `accessibilityLabel` у иконок-кнопок.
- [ ] Новый компонент/токен описан в этом файле.
