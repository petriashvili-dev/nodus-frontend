# Импорт и экспорт

Экран «Импорт и экспорт» в настройках работает через backend. Локальные архивы больше не создаются и не применяются непосредственно к SwiftData.

## Экспорт

`GET /v1/me/export` возвращает JSON с активными узлами пользователя. Клиент сохраняет исходные байты в системный файловый picker под именем из `Content-Disposition` (`nodus-export-YYYY-MM-DD.json`). При ошибке сети файл не создаётся.

## Импорт

Клиент читает текстовый файл и вызывает `POST /v1/me/import` с `content`, `file_name`, текущим IANA timezone и новым `Idempotency-Key`. Тело не попадает в Outbox: без сети показывается ошибка, импорт не ставится в очередь. Размер проверяется по `limits.import_max_chars`; для чужого файла при доступной `ai_import` действует меньший `import_ai_max_chars`.

- Файл Nodus (`source: nodus`) отправляется на прямой импорт; существующие записи не меняются.
- Другие текстовые, JSON и CSV файлы доступны только при `ai_import`. Перед передачей содержимого показывается серверное согласие AI.
- `200 mode: direct` сообщает число созданных узлов.
- `202 mode: ai` сохраняет импортное задание на сервере. Оно появляется из snapshot/delta и остаётся доступным после закрытия настроек и перезапуска.
- Готовое задание открывает `ImportJobReviewView`: можно снять отметки с отдельных строк, подтвердить выбранные индексы или отменить разбор. Узлы создаются сервером только после подтверждения и появляются на устройстве через Sync.
- Ключ и список индексов незавершённого подтверждения сохраняются в записи `ImportJob`; повтор сетевого запроса использует ту же пару ключ/тело, а бизнес-ошибка разрешает новую попытку с новым ключом.
- `403 feature_not_available` объясняется как возможность импортировать только файл Nodus; другие ошибки показываются пользователю без сохранения текста файла.

## Код

- `Data/Import/ImportExportService.swift` — файловый GET, импорт, подтверждение и отмена задания.
- `Data/AI/SuggestionDTO.swift`, `Models/ImportJob.swift` — DTO и локальное состояние задания.
- `Data/Sync/SyncEngine.swift` — snapshot/delta заданий.
- `Views/SettingsView.swift`, `Views/ImportJobReviewView.swift` — выбор файла и проверка preview.
- `nodusTests/ImportExportTests.swift` — серверный export и контракт прямого import.
