# Голосовые AI-черновики

Требования — §10 `03_Nodus_iOS_Requirements.md`, контракт — `nodus_backend/docs/ios/07-ai.md`. Доступ и согласие — [`01-ai-access.md`](01-ai-access.md).

## Поток

1. **Диктовка** — `VoiceInputComposer` (Speech, распознанный текст можно поправить). Кнопка есть только при `ai_drafts`.
2. **Согласие** — нет `ai_consent_at` → `AIConsentView` (что, кому, зачем, ссылка `links.privacy_policy` из app config). «Разрешить» — сразу локально и `PUT /me/ai-consent { granted: true }` через Outbox, затем текст отправляется.
3. **Отправка** — `POST /v1/ai/node-drafts { text, timezone, reference_time }` с новым `Idempotency-Key`, только онлайн. Текст до этого сохраняется в `AIDraftJob` — без сети запись остаётся в «Черновиках» со статусом «Ещё не отправлено».
4. **Ожидание** — `AIDraftsWaitingCard`: «Распутываем мысли…»; **только после `202`** — «Можно закрыть экран — сообщим, когда будет готово» и «Закрыть». Закрытие не отменяет задание.
5. **Готово** — задание приходит через sync (`entity_type: ai_draft_job`, SSE будит sync). Если карточка ожидания на экране — экран проверки открывается сам; иначе toast «Черновики готовы», задание ждёт в «Черновиках». Push `ai_drafts_ready` по нажатию ведёт на тот же экран ([07](07-push.md)).
6. **Проверка** — `AIDraftsReviewView`: черновики карточками, каждая открывает обычный `ReminderEditorView`; карточку можно исключить; замечания модели (`issues`) показаны на карточке, без даты — «Выбери дату и время», подтверждение недоступно.
7. **Подтверждение** — одна операция `POST /ai/node-drafts/{id}/confirm { nodes }`: узлы создаются локально и операция ставится в Outbox **одним `save`**, нить обновляется сразу. Отказ сервера (валидация, доступ) — узлы убираются, задание снова `ready`.

## «Черновики» в настройках

Пункт виден при `ai_drafts` или если есть незавершённые задания (после отзыва функции начатое доступно).

| Статус | Подпись | Действия |
|---|---|---|
| `unsent` | Ещё не отправлено | Отправить, Удалить |
| `queued` / `processing` | Распутываем мысли… | — |
| `ready` | Можно проверить | Проверить, Удалить (`…/cancel` через Outbox) |
| `failed` | Не получилось разобрать запись | Повторить (новое задание с сохранённым текстом и новым ключом), Создать вручную (редактор с текстом в названии), Удалить |
| `failed`, `nothing_recognized` | Не нашли дел в записи | Удалить |
| `expired` | Черновики устарели | Удалить |

## Ошибки отправки

| Ответ | Что видит пользователь |
|---|---|
| нет сети | «Нет связи. Запись сохранена в черновиках» |
| `403 ai_consent_required` | экран согласия (профиль перечитывается) |
| `403 feature_not_available` | «Эта функция сейчас недоступна», точка входа исчезает после обновления профиля |
| `429 ai_quota_exceeded` | «Лимит AI на сегодня исчерпан» |
| прочее | «Не получилось разобрать запись» |

## Siri

`CreateNodusNodesIntent` («Завязать узлы Nodus») отправляет текст тем же `AIDraftsService` через `AppServices.shared`: «Разбираю. Черновики будут ждать в Nodus.» Проверка — в приложении; из Siri ничего не создаётся. Без функции, без согласия, без сети, при лимите — короткий ответ без перехода.

## Устройство

| Файл | Роль |
|---|---|
| `Models/AIDraftJob.swift` | локальное задание: текст, пояс, момент диктовки, статус, черновики (JSON) |
| `Data/AI/AIDraftsService.swift` | согласие, отправка, подтверждение, отмена; `EditableDraft` — черновик для редактора |
| `Data/AI/AIDraftsCoordinator.swift` | состояние потока для нити, настроек и экранов |
| `Data/Sync/SyncEngine.swift` | `ai_draft_job` из sync и snapshot; операции `confirmAIDrafts`, `cancelAIDrafts` |

## Тесты

`nodusTests/AIDraftsTests.swift`: без согласия и без функции ничего не отправляется, принятое задание хранит текст под id сервера, офлайн-запись, `ai_consent_required`, согласие через Outbox, черновик без даты, подтверждение одной транзакцией, откат при отказе.
