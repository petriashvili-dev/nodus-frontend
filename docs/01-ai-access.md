# Доступ к AI-функциям

Требования — §9.1 `03_Nodus_iOS_Requirements.md`, контракт — `nodus_backend/docs/ios/07-ai.md` («Доступ к AI-функциям и согласие»).

## Принцип

Клиент не знает о планах и подписках. Сервер присылает список `user.features` (`ai_drafts`, `ai_continuations`, `ai_import`) и момент согласия `user.ai_consent_at`; клиент только решает, какие точки входа показывать и обрабатывать.

- Функции нет в `features` — точки входа **нет вовсе**: без замков, бейджей, «скоро», упоминаний Nodus+, подписки или тестирования.
- Нет поля `features` — считать `[]`; неизвестные ключи игнорировать.
- Согласие — только серверное `ai_consent_at`, локального флага нет.
- Клиент никогда не обращается к LLM напрямую: все AI-функции идут через backend.

## Устройство

| Файл | Роль |
|---|---|
| `nodus/nodus/Models/AIAccess.swift` | `AIFeature` (ключи сервера) и `AIAccess` (набор функций + `consentAt`), разбор `features` |
| `nodus/nodus/Services/AIAccessStore.swift` | последнее известное `AIAccess` в app group (`aiFeatures`, `aiConsentAt`); `apply(_:)` применяет изменения сразу, `load()` читает без main actor (для Siri-интента) |

`AIAccessStore` создаётся в `AppServices` и передаётся на главный экран. Пишет в него только серверный профиль: `AccountService` после `GET /v1/me` при запуске и возврате в foreground (`docs/02-api-and-account.md`), позже — sync `entity_type: user`. До первого ответа сервера хранилище пустое, и AI-точки входа скрыты.

## Точки входа

| Точка | Без функции | С функцией |
|---|---|---|
| кнопка диктовки на нити и в пустом дне (`HomeTimelineView`, `EmptyDayContent`) | скрыта (`ai_drafts`) | открывает голосовой composer |
| контрол «Voice Knot» в Пункте управления (`OpenVoiceInputIntent`) | остаётся установленным (скрыть его для отдельного пользователя нельзя); приложение открывается и показывает toast «Эта функция сейчас недоступна» | открывает composer |
| Siri «Завязать узлы Nodus» (`CreateNodusNodesIntent`) | остаётся в системе; отвечает «Эта функция сейчас недоступна.» | то же — пока не подключён backend-поток AI-черновиков |
| открытый composer, если функцию отозвали | закрывается | — |

Отправка текста из composer пока отвечает нейтрально: синхронный разбор через NeuroAPI удалён, а backend-поток AI-черновиков (`POST /v1/ai/node-drafts` → задание → экран проверки) — следующий шаг интеграции.

## Тесты

`nodus/nodusTests/AIAccessTests.swift` — разбор `features` (нет поля, неизвестные ключи), согласие, сохранение и чтение из app group, мгновенный отзыв.
